# 协作学习模式（Collaborative Learning Mode）

> 版本: v1.0 | 来源: 实战提炼（2026-06 至 08 与 AI 共同迭代，07-27 结构化定稿）

## 核心思想

这套模式回答一个根本问题：**人和 AI 一起学习时，边界画在哪里。**

不是让 AI 替学，而是让 AI 当「路径组织者 + 陪读者 + 书记员」——加速输入与整理，但**理解与判断永远属于学习者本人**。核心理念：**认知摩擦力不可外包。**

## 一、递进式协作学习五原则（2026-07-27 定稿）

不是零散技巧，而是一条由宏观到微观、由概念到细节、由理论到实践的完整递进协作链：

| # | 维度 | 原则 | 操作 |
|---|------|------|------|
| ① | 信息摄入顺序 | **先整体后局部** | 学习计划遵循事物发展规律与内在逻辑，先建立整体感知再逐步深入；从宏观历史脉络和主流架构分类入手建立系统认知 |
| ② | 节奏控制 | **由简及深** | AI 讲解前先判断学习者已有深度，从概念层面概述，确认后再按兴趣逐层深入；不跳过基础，不默认每次都深入三层 |
| ③ | 操作流程 | **四步固定范式** | 语义级拆解（全局视野）→ 多层次个性化解析（按认知状态/数学基础/目标分层）→ 检查点存档 → 分类收束整理到认知地图 |
| ④ | 认知策略 | **框架优先，细节后置** | 复杂知识先掌握语义直觉和整体框架，具体算法细节暂时搁置、后续单独深入，不要求当下展开全部推导 |
| ⑤ | 工程哲学 | **理论先于编码** | 系统架构设计及重大工程实现前，先夯实理论基础，形成可验证的逻辑链条再动手编码，避免空中楼阁 |

实战验证模式：**全局视野 → 学习者验收完整性 → 反馈修正 → 逐层深入**（世界模型论文带读、PETS 精读均按此运转）。

## 二、知识管理协作五规则（AI 角色边界）

| # | 规则 | 内容 |
|---|------|------|
| 1 | **AI 产出隔离** | AI 自身思考产出的内容不得记入学习者的知识地图，只记录学习者自己想清楚并确认过的内容——知识归属权属于学习者 |
| 2 | **AI 引导教学** | 表达学习意愿时，AI 不直接给答案，引导主动思考——认知摩擦力介入点在学习启动时，而非产出后整理 |
| 3 | **AI 笔记整理边界** | AI 整理笔记时不补充学习者未思考的内容，不替学习者完成认知环节 |
| 4 | **知识地图节点引用** | 引用节点直接用名称（如「基于模型的强化学习地图」），禁止编号代称（如 Bg09），便于定位 |
| 5 | **带读论文陪读** | 带读时 AI 不给答案，只负责：组织阅读顺序、铺好阅读路径、陪读——让学习者自己深入学习后形成判断 |

### 信息准入三重闸门（更早的三层递进约束）

知识纯净度（防止状态污染）→ 验证标准（内容须经个人确认）→ AI 产出隔离（隔离 AI 知识归属权）。

## 三、事实性内容验证协议栈（五层递进）

每一层继承上一层约束、再叠加专项规则——不是平行清单，而是层叠协议栈：

| 层 | 场景 | 专项约束 |
|----|------|---------|
| L1 通用原则 | 全局 | 非本人亲自确认的内容不记录 |
| L2 学术引用 | 引用文献 | 验证文献性质（原始论文/观点文/综述/实证/理论推导），引用权重分级标注，禁止模糊引用掩盖理论空缺，批判性结论归档为正式成果 |
| L3 知识体系构建 | 知识地图 | 仅基于可追溯标签做判断，禁止 AI 自行推断置信度；理论成熟度四等级：经典闭环 / 成熟未闭合 / 有论文支撑 / 概念阶段 |
| L4 学术调研 | 调研 | 时间/人名/数字逐条溯源；arXiv ID 前缀交叉验证论文日期；官方发布公告验证产品日期 |
| L5 调研计划 | 长期追踪 | 不预设时间锚点，迭代式更新至最新日期，引用树不停留在旧年份 |

## 四、五层递进式学习体系（底层结构全景）

```
知识地图法（底层结构）→ 实践闭环法（执行验证）→ 信息治理法（输入质量）
→ 递进式学术法（深度理解）→ 系统设计先理论后编码（工程统一）
```

每一层建立在上一层认知基础上：知识地图提供结构，实践闭环增加执行验证，信息治理控制输入质量，递进式学术法解决深度理解，理论先编码指向工程落地。

## 五、配套方法论

### R1-R5 深度研究工作法

复杂深度研究任务严格遵循：R1 迭代式调研（多轮递进深挖）→ R2 网络校验（跨源交叉验证）→ R3 里程碑归档（关键节点固化）→ R4 双轴追踪（时间+主题双维）→ R5 事实溯源（逐条数据回溯验证）。

### 课堂书记员模式

上课/直播时 AI 当「实时书记员」：实时解析截图与文字、即时结构化沉淀；课后统一整理进笔记。延续同一认知分工：AI 负责加速输入与整理，学习者负责深度理解。

### 思考题设计

延续陪读规则：AI 出题不给答案，学习者先自行回答（如精读前的思考问题），再进入讨论。

### 地图驱动学习闭环

```
前置知识从知识地图节点抽取 → 学完的新内容按「已学内容可加」挂回地图
→ 地图再驱动下一步学习
```

知识地图承担「学习路径规划」职能，形成双向闭环——这也是知识地图法与本文档的衔接点。

### 3.6 数学概念精确图表辅助（2026-08-22 新增）

讲数学概念（如高斯分布、概率密度）时，**禁止用 ASCII 图/文字画图**（不精确、误导理解），改用 `matplotlib` 等库生成**数学上精确的曲线/图表**：

- 一图一概念：μ 平移一张、σ 胖瘦一张、CEM 采样对比一张——用 `subplots` 拼多张小图，每张回答一个具体困惑
- 图是公式的几何直觉，公式是图的代数表达：先看图建立直觉，再回到公式（配合原则④框架优先）
- 中文标签需设中文字体（PingFang SC 等）；`scipy` 常缺失 → 用 numpy 手写公式
- 图要可验证（生成脚本保留，用户能重跑），以图片形式交付
