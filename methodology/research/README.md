# 论文调研法（Research Methodology）

> 版本: v1.0 | 来源: 实战提炼（日报双层分析管线、38 篇论文调研、单篇精读前置链）

## 核心思想

论文调研不是「读论文」，而是**一条有产出的管线**：从海量文献到可行动的知识，每一步都有明确方法、可验证的标准。

四条子方法可独立使用，也可串成完整管线：

```
选题/需求 → 覆盖矩阵（全面摸底）→ 四线交叉（深度分析）
         → 双层筛选（从多到精）→ 前置知识链（精读准备）
```

## 一、覆盖矩阵法（全面摸底）

**适用**：开始一个新主题时，确保调研不遗漏。

### 做法

1. 拆解主题的**关键维度**（如：存储/应用/自进化/闭环评估）
2. 每个维度列出已有工作与空白
3. 交叉验证：检查每个「维度 × 方法」组合是否被覆盖

### 案例

- 图记忆调研：四维度覆盖矩阵（存储、应用、自进化、闭环评估）→ 定位空白
- 世界模型调研：五主题覆盖（智能本质论 9 / 控制论与内模原理 4 / 预测性心智理论 7 / 世界模型数学基础 9 / 世界模型工程 9）→ 38 篇论文归位

### 产出

一张覆盖矩阵表（维度 × 方法，标注已有/空白），是调研范围的事实依据。

## 二、四线交叉分析（深度分析）

**适用**：对一组文献做深度交叉分析，得出结构化结论。

### 四条线

| 线 | 问题 | 产出 |
|----|------|------|
| D1 文献综述 | 这个领域在解决什么问题 | 问题谱系 |
| D2 技术路线 | 主流方案是什么，如何演进 | 路线图 |
| D3 能力边界 | 现有方案做不到什么 | 空白清单 |
| D4 落地验证 | 哪些方案真正可用 | 验证矩阵 |

### 做法

每条线独立梳理 → 交叉比对 → 交叉点即洞察（如「D3 的空白恰好是 D4 验证出的坑」）。

## 三、双层论文分析管线（从多到精）

**适用**：持续追踪大量论文（如每日/每周新增），快速定位值得精读的 Top 候选。

### 第一层：批量粗筛（LLM 并发分析）

- 单次调用稳定边界：**≤10 篇**（超出分批）
- 每篇产出：中文翻译 + 评分 + 决策

### 混合加权评分（硬指标 60% + LLM 软指标 40%）

- 硬指标：引用数、年份、venue、作者活跃度
- 软指标：LLM 对新颖度/相关度/质量的判断
- 门禁：**立即推 ≥ 7.0 / 等周报 ≥ 5.0 / 跳过 < 5.0**

### 第二层：Top 候选深度阅读

- 只对第一层筛出的少量候选做原文精读
- 产出：深度解读 + 推荐理由

### 经验

- 10 篇 × 20 组采样拟合，决策准确率 ~90%
- **数据质量约束必须前置到采集层**：不能依赖下游行为保证质量

## 四、前置知识链（精读准备）

**适用**：精读一篇高难度论文前，确保前置知识就绪。

### 做法

1. 列出目标论文依赖的核心概念
2. 为每个概念找到**知识地图中已有的节点**（优先自己的地图）
3. 缺失的 → 排定阅读顺序（前置 → 目标）

### 案例

精读 PETS（2018 NIPS，概率集成 + 轨迹采样 + CEM 规划）前，梳理 8 篇前置：
MBRL 综述 → 神经网络逼近论 → 世界模型动力学 → MBPO → 最大熵探索 → 三重等价 → Black-Scholes → 控制论

## 五、科研方法论（数据缺口视角）

> 2026-08 定稿：做研究前先问「决定性的信息空缺是什么」

```
拆清业务逻辑 → 识别决定性信息空缺 → 补数据
```

补数据思路取决于科研品味。案例矩阵：

| 项目 | 业务逻辑 | 决定性数据缺口 | 补法 |
|------|---------|--------------|------|
| qunribao | 群日报自动生成 | 反馈信号 | 纠错/补充/认可 5 类反馈机制 |
| img-iter-agent | 生图 Agent 自迭代 | 偏好评估数据 | 混合评分 + 人工排序校准 |
| 客厅世界 | 视觉→结构化空间参数 | 尺寸数据 | 单目尺寸推理 |

## 六、配套工具

- 每日简报管线：`research-brief`（S2 + arXiv 双层分析）→ 在工具层/已开源技能中引用
- 翻译管线：`pdf-paper-translation`（pdf2zh + LLM，批量翻译论文）
- 知识挂载：精读完成的论文按「已学内容可加」规则挂为知识地图实例层节点
