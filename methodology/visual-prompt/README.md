# 视觉 Prompt 法（Visual Prompt Methodology）

> 版本: v1.0 | 来源: 实战提炼（V15 工作流、极简拓扑规范、开源头图规范、论文可视化范式）

## 核心思想

视觉 Prompt 不是「写一段提示词碰运气」，而是一条**从内容到画面的翻译管线**。核心原则：

1. **先拆解内容**：理解文章/项目的核心观念与结构
2. **再选视觉语言**：根据场景选择风格体系（不是每个场景都用同一套模板）
3. **后结构化表达**：用固定的提示词框架约束质量

## 一、V15 扁平符号与构成视觉工作流（封面/配图首选）

**适用**：把文字内容（笔记、文章、报告）转化为纯平二维插画封面。

### 六步分析（Phase 0-3 管线）

```
Phase 0  输入内容（笔记 ID 或文本）
Phase 1  生成 3 个视觉方案（每个含设计说明 + 完整英文 Prompt）
Phase 2  用户选定方案
Phase 3  生图 + 应用（封面/头图/交付）
```

### V15 核心法则

- **扁平符号化**：用纯平二维图形表达抽象概念
- **构成主义**：讲究点线面构成关系，而非写实
- **留白**：信息密度克制，突出核心符号

### 案例

- 量化学习总结封面：3 方案供选 → 选定方案 3 生图（2026-07-31 实战验证）

## 二、极简拓扑视觉规范（抽象意境场景）

**适用**：需要「高级感、氛围感」的抽象视觉（个人品牌、作品集、概念图）。

### 核心视觉法则

| 法则 | 内容 |
|------|------|
| 形态克制与留白 | 基础几何拓扑/流体/有机形态，拒绝机械堆砌 |
| 质感表达 | 复杂度来自材质碰撞，而非造型繁复 |
| 绝对纯净 | 严禁文本、字母、UI 元素、具象现实物品 |

### 材质系统（按语义选择）

| 材质 | 隐喻 |
|------|------|
| 纳米陶瓷 | 理性、标准化、系统基建 |
| 温润琉璃 | 信任沉淀、价值核心 |
| 虹彩玻璃 | 视角穿透、逻辑透明 |
| 有机笔触 | 个人品位、不可复制的感性 |
| 动态流体/气云 | 未定义潜能、AI 原始算力 |
| 阳极金属 | 硬核约束、效率杠杆 |
| 拓扑网格 | 协同、社交链接、信号释放 |
| 柔光树脂 | 包容度、软性规则 |
| 原生矿岩 | 原始数据、灵感火花 |

### 渲染基准

- Light：暖白底 `#F5F3ED` + 巨大柔光箱高调打光
- Dark：深空黑 `#0A0A0A` + 边缘光
- 长焦微距 100mm+，极浅景深，2% 单色胶片噪点

## 三、开源项目头图规范（项目封面首选）

**适用**：GitHub 项目封面、开源视觉、技术类头图。

### 视觉框架

- **氛围**：工业级极简 + 高精度技术美学，深灰底 `#0D0D0F ~ #121214`
- **光影**：双色对冲——左上冷调（输入/变量）+ 右下暖调（输出/洞察）
- **纹理**：极细辅助线/极坐标网格/数据点阵，透明度 5%-12%
- **比例**：4:3（社媒/幻灯片）或 2.5:1（横幅）

### 核心视觉中心

- **「熵减」可视化**：从无序到有序、从半透明到实体的质感转变
- 主体材质：磨砂玻璃 + 细线框架 + 发光几何体（圆环/立方/多面体）
- 动线：输入端线条随机发散 → 输出端平行收敛
- 节点：主体内部 3-5 个高亮功能锚点

### 信息编排

```
顶部：元数据（等宽字体，极小字号，40-60% 不透明度）
中部：主标题（加粗纯白，字距拉开）+ 副标题（细体，行动感）
底部：2-3 栏功能解构（线性图标 + 粗体短标题 + 低透明描述）
底部边缘：玻璃态 Dock（毛玻璃 + 细白边框，放项目入口/GitHub 链接）
```

### 色彩纪律

- 全局 ≤3 色，用明度/不透明度创造深度，不堆砌色相
- 关键词：**秩序 (Order)、精密 (Precision)、透明 (Transparency)**

### 实战案例

- star-fit / z-winnow / img-iter-agent 三项目封面（2026-08-16）
- ZENTHOS GitHub 个人主页横幅

## 四、论文可视化范式（学术配图）

**适用**：论文/概念可视化，需要「准确 + 有设计感」。

### 新范式（2026-07 定稿）

- 不再写布局/风格约束（"上方/下方/箭头/框"）
- 改用：**英文意译 + 核心内容点 + `--image-search` 自主构图**
- 让图像模型理解概念后自主决定视觉隐喻与结构
- 末尾统一指定：中文标题 + 配色氛围

## 五、生图工具选型（模型路由）

| 场景 | 工具 | 原因 |
|------|------|------|
| 有知识但不知如何构图 | quick-img（Gemini Flash Image） | 自主构图 + 网络搜索参考图 |

| 精确画面设计已定 | gpt-image-2 | 提示词完全指定，不让模型代劳构图 |
